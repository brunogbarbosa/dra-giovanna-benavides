# Dra. Giovanna Benavides — Face Design

Site institucional da Dra. Giovanna Benavides, criadora do Método Signature Face™.

## Experiência

- Identidade editorial responsiva em marfim, sálvia e dourado
- Apresentação do método, tratamentos, resultados e trajetória profissional
- Agendamento integrado ao canal oficial
- SEO, Open Graph e favicon personalizados
- Otimização de imagens e acessibilidade para navegação por teclado

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
```
